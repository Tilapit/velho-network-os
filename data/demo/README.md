# Demo data

Every person, company, post, comment and signal in this folder is invented
for the Velho Network OS demo. No real LinkedIn data.

| File | What it stands in for |
| --- | --- |
| Connections.csv | LinkedIn's own export (Settings → Data privacy → Get a copy of your data → Connections). Same columns and preamble. |
| posts.csv | The founder's posts with a topic tag |
| engagement.csv | Who reacted to or commented on which post, prepared by hand for a few posts |
| customers.csv | Current and previous customers, with where the lead came from |
| interactions.csv | The founder's own log of meetings, DMs and emails |
| relationships.csv | Introduction paths the founder has been told about |
| companies.csv | Company size and industry from public sources |
| signals.json | Output of the separate company-signal pipeline |

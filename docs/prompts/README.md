# Prompts

This was built at the Aaltoes Operations Hackathon, a prompt operations
hackathon, so the prompts are part of the work. These are the written briefs
Claude Code worked from, in the order they were used. Later, shorter requests
were typed into the session directly and show up in the git log.

| # | Prompt | What it asked for |
|---|---|---|
| 1 | [MOCK_DATA_PROMPT.md](MOCK_DATA_PROMPT.md) | A realistic mock LinkedIn export (about 1,500 invented connections) to build against before touching real data |
| 2 | [NETWORK_DEMO_PROMPT.md](NETWORK_DEMO_PROMPT.md) | The core: import the team's exports, match companies in PRH, show who could need Velho and why |
| 3 | [PRODUCTION_MCP_PROMPT.md](PRODUCTION_MCP_PROMPT.md) | From demo to pilot: the MCP server the founders use from their own Claude |
| 4 | [OVERNIGHT_PROMPT.md](OVERNIGHT_PROMPT.md) | The overnight build, unattended: a working, good-looking demo by morning (wins on conflict) |
| 5 | [OVERNIGHT_2_PROMPT.md](OVERNIGHT_2_PROMPT.md) | Overnight, part 2: polish, proof on real data, Claude-ready |

`PROGRESS.md` in the repository root is the log of what was built from them,
with every decision. The people and companies in the prompts' examples are
invented; no real contact data is in this folder.
